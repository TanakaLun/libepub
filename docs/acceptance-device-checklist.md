# libepub 真机验收清单

> 自动化闸门已覆盖解析、级联、布局、分页、Robolectric 交互；本清单是**只能在真机/模拟器上确认**的视觉与性能项。
> 建议设备：Android 10+，至少 1080×1920；先用 `./gradlew :app:assembleDebug` 安装
> `app/build/outputs/apk/debug/app-debug.apk`。

## 0. 准备

- [ ] `adb install -r app/build/outputs/apk/debug/app-debug.apk`
- [ ] 打开应用，书架列出 `assets/` 中的样书（仓库不带版权样书，先放一本进去；本次验收用《无职转生 07》）
- [ ] `adb shell dumpsys gfxinfo org.libepub.app reset`（进入阅读器前重置）

## 1. 冷启动 < 1s

- [ ] 强制停止后点击图标，`adb shell am start -W -n org.libepub.app/.MainActivity`，
      `TotalTime` 记录：______ ms（目标 < 1000）
- [ ] 书架 → 点书 → 首屏可读，记录：______ ms（目标 < 1000）
- [ ] 返回书架再进同一本，明显更快（缓存命中）

## 2. 翻页流畅度（60fps）

- [ ] 翻页模式连续翻 20 页，无掉帧/白屏/闪动
- [ ] `adb shell dumpsys gfxinfo org.libepub.app` 中 `Janky frames` 占比 < 5%
- [ ] 快速左右滑动不会跳页、不会卡在半页
- [ ] 章节边界翻页自然（最后一页 → 下一章第一页）

## 3. 排版保真（横排）

- [ ] 段首 2em 缩进、`line-height:130%`、`text-align:justify` 两端对齐
- [ ] 多看单图（`duokan-image-single`）居中、等比缩放、不超页宽
- [ ] 图集 cell 依次排列，点击进入图集查看
- [ ] 脚注标记显示为 **【注】**（不是 note.png 图片）
- [ ] 点击【注】弹出脚注卡片，内容使用书中样式（DK-SONGTI 缺失时回退默认字体且有日志）
- [ ] 关闭脚注后页码/位置不变
- [ ] 书内「目录」页（contents.xhtml）的章节链接可点击，跳转到对应章节
- [ ] 正文中的内部链接可点击跳转（同章 fragment 定位到锚点）
- [ ] 粗体/斜体/下划线/删除线/上标下标正常
- [ ] ruby（注音）在基字上方居中；长注音均分到多字
- [ ] `text-emphasis` 着重号（`.em-dot` 圆点）落在字上方且间距均匀
- [ ] 多图页面滚动/翻页不丢图、不重叠

## 4. 竖排（vertical-rl）

- [ ] 设置 → 排版方向切到「竖排（右起）」：正文从右向左成列
- [ ] CJK 直立，拉丁字母/数字旋转 90°
- [ ] 着重号在字的**右侧**，ruby 在基字**右侧**
- [ ] 下划线出现在列的左侧（block-after 侧）
- [ ] 翻页方向符合竖排习惯（向左翻/下一页从右侧进入）
- [ ] 切回横排后位置仍停在当前段落附近

## 5. 滚动模式

- [ ] 设置 → 阅读模式切到「滚动」：整章连续滚动，无重新排版闪烁
- [ ] 从目录跳转后自动滚到目标锚点
- [ ] 滚动时底部进度百分比单调变化
- [ ] 切回翻页模式仍停留在当前段落

## 6. 目录 / 设置 / 进度

- [ ] 翻页模式下**每一页**都有对应文字（不是只有每章第一页有字）
- [ ] 翻页模式每页最后一行停在底栏/导航栏上方，不贴底、不被遮挡
- [ ] 文字页每页顶部留白一致，首行不被「返回/目录/设置」顶栏遮挡（不要求整页垂直居中）
- [ ] 滚动模式正文可滚到底栏/导航栏下方（沉浸），滚到章末时最后一行能完整露出（章末追加空白，而不是缩小可视区）
- [ ] 纯图片页（封面、彩页）在页面内水平且垂直居中，不顶在容器顶部

- [ ] 目录按钮打开层级目录，点击条目跳转正确章节
- [ ] 跳转带 fragment 的条目会定位到对应锚点
- [ ] 字号 A+/A- 立即生效，位置保持在同一段落附近
- [ ] 主题切换（纸张/复古/夜间）文字与背景对比正常，图片不反色
- [ ] 退出应用再进入，恢复到上次章节/页
- [ ] 旋转屏幕后不崩溃、位置基本保持

## 7. 图片交互

- [ ] 单图点击 → 全屏容器，双指可放大/平移，关闭复位
- [ ] 图集左右滑动切换，页码指示 `n / m` 正确
- [ ] 关闭图集回到原页，位置不变
- [ ] 图片大图页/图集/脚注/设置都支持**系统返回手势**逐层关闭；阅读页再返回书架
- [ ] 缺失图片显示占位块，不崩溃（可用改包名/删图验证）

## 8. 内存与稳定性

- [ ] 连续翻 5 章、开合脚注/图集 20 次，`adb shell dumpsys meminfo org.libepub.app`
      的 `TOTAL PSS` 稳定（无持续增长）
- [ ] 后台 5 分钟回来不重排整本书（秒回当前页）
- [ ] 无网络权限、无 JS 执行（`dumpsys package` 中无 INTERNET）

## 9. 系统栏 / 边到边

- [ ] 状态栏（含刘海/挖孔）区域不被顶栏按钮或正文遮挡
- [ ] 手势导航/三键导航下，底部进度条不被导航栏遮挡
- [ ] 顶栏、底栏都在安全区内；横屏旋转后仍然正确
- [ ] 纸张/复古主题下状态栏图标为深色且可见；夜间主题下为浅色
- [ ] 打开大图/图集时，关闭按钮避开状态栏；底部页码避开导航栏
